# Working on this repo

- Requirements are in `docs/requirements.md`.
- Build only the requirement IDs named in the prompt. Do not change behaviour for any requirement that is not named.
- Write an automated test for each acceptance criterion before building it, named by ID and AC (e.g. "PRD-07 AC2"). Keep all existing tests passing.
- Before any work, read `docs/how-it-works.md` (how the app works, its rules and past decisions). Update it in the same change whenever behaviour, screens, rules or the go-live steps change, and add any new decision to its decisions log.
